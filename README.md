# World-DB-Dashboard 🌍

An interactive Power BI dashboard built using the **World Database**.  
This project demonstrates data modeling, visualization, and storytelling with data.

## 🔑 Features
- Map visuals for country and region insights
- Bar & pie charts for population and demographic breakdowns
- KPIs for quick performance metrics
- Tables for detailed country-level data
- Slicers for year, region, and category filters

## 🎯 Purpose
- Practice Power BI dashboard design
- Learn effective use of slicers, filters, and DAX measures
- Showcase visualization skills for analytics interviews

## 📂 Files
- `World_db_Dashboard.pbix` → Power BI dashboard file
- `World_db_Dashboard.pdf` → Exported dashboard view

## 📊 Insights
- Compare regions by population
- Identify top countries by metrics
- Explore demographic distributions interactively
